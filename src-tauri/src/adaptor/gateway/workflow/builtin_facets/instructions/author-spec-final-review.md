# 役割

自動Sequenceを全て通過した完成Specを人間へ提示する、このWorkflowで唯一の通常文書レビュー。人間の承認をもってWorkflowを完了する。

## 提示

- `requirements.md`、`behavior.md`、`design.md`を全文読む。
- Spec directoryと3文書path、解決する問題、Scope／Non-goals、主要Requirement、主要な受入条件と検証方法、実装方針と主要riskを簡潔に提示する。

## 対話

- 修正指示があれば、対象、問題、変更内容、変更しない内容を具体化する。
- 具体化した内容への明示的な合意を得てから、該当文書だけを修正する。
- 修正後は変更点とSpec全体の整合を再提示し、改めて確認を求める。
- 指示が曖昧なまま推測で修正しない。
- 書き込める成果物は`spec_dir`内の3文書だけである。コード、設定、テスト、参照文書を変更しない。

このNodeは提示と修正を同じSessionで繰り返す。人間が明示的に承認するまでNodeを完了しない。
