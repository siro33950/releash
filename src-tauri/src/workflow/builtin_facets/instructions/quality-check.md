{{project_name}} プロジェクトの品質チェック（lint/test/build）を実行し、失敗があれば修正する。

## プロセス

### 1. 品質チェック実行

プロジェクトの標準的な品質ゲートコマンドを実行する。正確なコマンドはプロジェクトの設定ファイル（CLAUDE.md、CI設定）を参照する。一般的なチェック:

**フロントエンド:**
- lintチェック（例: `pnpm lint`）
- ユニットテスト（例: `pnpm test`）
- ビルド（例: `pnpm build`）

**バックエンド（Rust）:**
- フォーマットチェック（例: `cargo fmt --check`）
- lint（例: `cargo clippy -- -D warnings`）
- テスト（例: `cargo test`）

### 2. 失敗の修正

各失敗について:
1. エラー出力から根本原因を特定する
2. 修正を適用する
3. 失敗したチェックを再実行する
4. 失敗ごとに最大3回まで繰り返す

### 3. 結果報告

サマリーを提示する:

| チェック | 結果 |
|---------|------|
| lint | PASS/FAIL |
| test | PASS/FAIL |
| build | PASS/FAIL |

3回試行後もまだ失敗するチェックがあれば、失敗の詳細を報告する。
