## B-001: worktree のファイルの木

GIVEN worktree を選んでいる
WHEN 利用者が右の「ファイル」の面を開く
THEN worktree の直下のファイルとディレクトリが木に出る
AND `.git` ディレクトリは出ない

## B-002: ディレクトリを開いたときに中身を読む

GIVEN 「ファイル」の面に、閉じたディレクトリがある
WHEN 利用者がそのディレクトリを開く
THEN そのディレクトリの直下のファイルとディレクトリが木に出る
AND 開いていないディレクトリの中身は読まれない

## B-003: git の状態の色

GIVEN worktree に、変更のあるファイル、`.gitignore` で除外されたファイル、変更のあるファイルを含む閉じたディレクトリがある
WHEN 利用者が「ファイル」の面を見る
THEN 変更のあるファイルは、その状態の色で出る
AND 変更のあるファイルを含む閉じたディレクトリは、中の変更の色で出る
AND 除外されたファイルは薄く出る

## B-004: 木への変化の反映

GIVEN 「ファイル」の面で、あるディレクトリを開いている
WHEN そのディレクトリにファイルが足される、またはそのディレクトリのファイルの git の状態が変わる
THEN 利用者の操作なしに、足されたファイルと変わった状態が木に出る

## B-005: 木からファイルタブを開く

GIVEN focus 中の pane に、あるファイルのタブが無い
WHEN 利用者が「ファイル」の面でそのファイルを開く
THEN focus 中の pane に、そのファイルのファイルタブが新しく開く

## B-006: 開いているタブを選ぶ

GIVEN focus 中の pane に、あるファイルのファイルタブがある
WHEN 利用者が「ファイル」の面で同じファイルを開く
THEN そのタブが選ばれる
AND 新しいタブは増えない

## B-007: 変更の無いファイルを開く

GIVEN 開くときの比較で変更の無いファイルがある
WHEN 利用者がそのファイルをファイルタブで開く
THEN 作業ツリーのファイルの内容が File 表示で出る

## B-008: 変更のあるファイルを開く

GIVEN 開くときの比較で変更のあるファイルがある
WHEN 利用者がそのファイルをファイルタブで開く
THEN 差分が Diff 表示で出る
AND 帯に追加行数と削除行数が出る

## B-009: File 表示への切替

GIVEN 変更のあるファイルが Diff 表示で開いている
WHEN 利用者が帯で File 表示に切り替える
THEN 作業ツリーのファイルの内容が出る

## B-010: HEAD 比較

GIVEN ファイルに、stage 済みの変更と stage していない変更がある
WHEN 利用者が帯で HEAD 比較を選ぶ
THEN HEAD から作業ツリーまでの、stage 済みと stage していない変更がどちらも差分に出る

## B-011: base 比較

GIVEN worktree の branch に base branch が設定され、base branch から commit 済みの変更があるファイルがある
WHEN 利用者が帯で base 比較を選ぶ
THEN base branch から作業ツリーまでの変更が差分に出る

## B-012: 上下 / 左右の切替

GIVEN 変更のあるファイルが Diff 表示で開いている
WHEN 利用者が帯で上下 / 左右を切り替える
THEN 差分が選んだ並べ方で出る

## B-013: 変更箇所のみ

GIVEN 変更の無い範囲を持つファイルが、全文で Diff 表示に開いている
WHEN 利用者が帯で「変更箇所のみ」を選ぶ
THEN 変更の無い範囲が畳まれて出る

## B-038: 全文

GIVEN 変更の無い範囲を持つファイルが、変更箇所のみで Diff 表示に開いている
WHEN 利用者が帯で「全文」を選ぶ
THEN 変更の無い範囲が開いて出る

## B-014: Diff 表示の帯の項目

GIVEN 変更があり、未解決の Thread が付いたファイルが、ファイルタブに Diff 表示で開いている
WHEN 利用者が帯を見る
THEN ファイルの path、比較の選択、追加行数と削除行数、File / Diff、上下 / 左右、変更箇所のみ / 全文、未解決の Thread の件数、「外部エディタで開く」が、横にスクロールせずに見える

## B-040: File 表示の帯の項目

GIVEN ファイルがファイルタブに File 表示で開いている
WHEN 利用者が帯を見る
THEN ファイルの path、File / Diff、未解決の Thread の件数、「外部エディタで開く」が、横にスクロールせずに見える
AND 比較の選択、追加行数と削除行数、上下 / 左右、変更箇所のみ / 全文は出ない

## B-015: 外部エディタで開く

GIVEN ファイルがファイルタブで開いている
WHEN 利用者が帯の「外部エディタで開く」を押す
THEN そのファイルが外部エディタで開く

## B-016: 色付けと markdown

GIVEN markdown のファイルと、ほかの言語のファイルがある
WHEN 利用者がそれぞれをファイルタブで開く
THEN どちらの文字も、ファイルの言語に応じて色付けされて出る
AND markdown のファイルは、整形した見た目ではなくコードとして出る

## B-017: 明暗

GIVEN ファイルがファイルタブで開いている
WHEN システムの明暗の設定が変わる
THEN ファイルタブの中の明暗が、システムの設定に合う

## B-018: HEAD 比較の hunk の stage

GIVEN HEAD 比較の Diff 表示に、stage していない hunk がある
WHEN 利用者がその hunk の stage の操作を行う
THEN その hunk が stage される
AND その hunk に stage 済みであることが出る

## B-019: HEAD 比較の hunk の unstage

GIVEN HEAD 比較の Diff 表示に、stage 済みの hunk がある
WHEN 利用者がその hunk の unstage の操作を行う
THEN その hunk が unstage される
AND その hunk に stage していないことが出る

## B-020: base 比較では stage を出さない

GIVEN 変更のあるファイルがファイルタブで開いている
WHEN 利用者が帯で base 比較を選ぶ
THEN hunk の stage 状態と、stage / unstage の操作が出ない

## B-021: 行の間の Thread

GIVEN ファイルの行に、未解決の Thread と解決済みの Thread が付いている
WHEN 利用者がそのファイルを Diff 表示で開く
THEN それぞれの Thread が、付いた行の間に出る
AND 未解決の Thread は開いて出る
AND 解決済みの Thread は畳んで出る

## B-022: Thread への返信

GIVEN 行の間に未解決の Thread が出ている
WHEN 利用者が返信を書いて送る
THEN 返信がその Thread に足されて出る

## B-023: Thread の解決

GIVEN 行の間に未解決の Thread が出ている
WHEN 利用者がその Thread を解決する
THEN その Thread が解決済みになり、畳んで出る
AND 帯の未解決の Thread の件数が 1 減る

## B-024: Thread の作成

GIVEN ファイルが Diff 表示で開いている
WHEN 利用者がマウスで行を選び、本文を書いて Thread を作る
THEN 選んだ行に Thread が付き、行の間に出る

## B-025: 開いているファイルの変化の反映

GIVEN ファイルがファイルタブで開いている
WHEN そのファイルの内容、stage 状態、Thread のどれかが、ファイルタブの外で変わる
THEN 利用者の操作なしに、変わった内容がファイルタブに出る

## B-026: 画像の差分

GIVEN 変更のある画像のファイルがある
WHEN 利用者がそのファイルをファイルタブで開く
THEN 前の画像と後の画像が左右に並んで出る

## B-027: 追加と削除の画像

GIVEN 追加された画像のファイルと、削除された画像のファイルがある
WHEN 利用者がそれぞれをファイルタブで開く
THEN 追加された画像は後の画像だけが出る
AND 削除された画像は前の画像だけが出る

## B-028: 変更の無い画像

GIVEN 変更の無い画像のファイルがある
WHEN 利用者がそのファイルをファイルタブで開く
THEN その画像が出る

## B-029: 大きいテキストファイル

GIVEN 1 MiB を超え、5,000 行を超えるテキストファイルがある
WHEN 利用者がそのファイルをファイルタブで開く
THEN ファイルの中身が出る

## B-039: hunk の多い差分

GIVEN 300 を超える hunk を持つ差分のあるテキストファイルがある
WHEN 利用者がそのファイルを Diff 表示で開く
THEN 差分の中身が出る

## B-032: 画像以外のバイナリ

GIVEN 画像以外のバイナリのファイルがある
WHEN 利用者がそのファイルをファイルタブで開く
THEN 中身は出ない
AND 表示しない理由、大きさ、「外部エディタで開く」が出る

## B-033: ファイルタブの復元

GIVEN ファイルタブで、あるファイルを File / Diff と比較を選んで開いている
WHEN 利用者が別の worktree を選んでから元の worktree を選び直す、またはアプリを起動し直す
THEN 同じファイルのファイルタブが、同じ File / Diff と比較の選択で開く

## B-034: 表示形式の設定値

GIVEN ファイルタブが 2 つ Diff 表示で開いている
WHEN 利用者が一方のタブの帯で、上下 / 左右または変更箇所のみ / 全文を切り替える
THEN もう一方のタブにも同じ選択が効く
AND アプリを起動し直しても、その選択が保たれる

## B-035: 比較の初期値

GIVEN アプリの設定値に base の既定が無い
WHEN 利用者が変更のあるファイルを新しいファイルタブで開く
THEN HEAD 比較で開く

## B-036: ネットワークに頼らない表示

GIVEN 外部のネットワークに接続できない
WHEN 利用者がファイルをファイルタブで開く
THEN ファイルの中身が出る

## B-037: 回帰の E2E

GIVEN macOS の回帰の E2E を回す
WHEN E2E が、変更のあるファイルをファイルタブで開く操作と、「ファイル」の面からファイルを開く操作を行う
THEN E2E が、差分が出ることと、ファイルタブが開くことを確かめて成功する
