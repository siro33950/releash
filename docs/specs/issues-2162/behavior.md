## B-001: Workspace の切り替えで購読するファイルタブ

GIVEN ある Workspace の右の「ファイル」の面で、一つの pane に複数のファイルタブが開いている
AND 利用者が別の Workspace を選択している
WHEN 利用者が、右の「ファイル」の面を開いたまま、元の Workspace を選択する
THEN アプリは、選択中のファイルタブについて、ファイルの内容と差分、およびそのファイルの Thread を購読する
AND アプリは、選択していないファイルタブについては購読しない

## B-002: 選択を外れたファイルタブの購読の停止

GIVEN 一つの pane に複数のファイルタブが開いており、アプリが選択中のファイルタブについて購読している
WHEN 利用者が、同じ pane の別のファイルタブを選ぶ
THEN アプリは、選択を外れたファイルタブについての購読を停止する
AND アプリは、新しく選ばれたファイルタブについて購読する

## B-003: 分割した pane ごとの購読

GIVEN 右の「ファイル」の面が二つの pane に分割されており、それぞれの pane に複数のファイルタブが開いている
WHEN 利用者が、右の「ファイル」の面を開く
THEN アプリは、それぞれの pane の選択中のファイルタブについて購読する
AND アプリは、どちらの pane でも、選択していないファイルタブについては購読しない

## B-004: 選んだファイルタブに出る内容

GIVEN 選択していないファイルタブがある
AND 選択していない間に、そのファイルの内容が変更された
WHEN 利用者が、そのファイルタブを選ぶ
THEN そのタブに、変更後のファイルの内容と差分が表示される
AND そのタブに、そのファイルの Thread が表示される

## B-005: 選び直したファイルタブの表示の保持

GIVEN 利用者が、あるファイルタブの中身をスクロールし、行に Thread の作成の入力を書きかけ、既にある Thread に返信の入力を書きかけている
WHEN 利用者が、同じ pane の別のファイルタブを選び、続けて元のファイルタブを選び直す
THEN 元のファイルタブは、選択を外す前のスクロール位置で表示される
AND 書きかけの Thread の作成の入力が残っている
AND 書きかけの返信の入力が残っている

## B-006: 購読を始めてから内容と Thread が届くまでの表示

GIVEN 一度中身を表示したファイルタブがあり、利用者が同じ pane の別のファイルタブを選んでいる
WHEN 利用者が、元のファイルタブを選び直す
THEN そのファイルの内容と Thread の両方が届くまで、そのタブに読み込み中であることが表示される
AND ファイルの内容だけが届いた時点では、読み込み中の表示が続く
AND 選択を外す前に表示していた内容は表示されない

## B-007: 選択を外れたファイルタブの中身の破棄

GIVEN 一つの pane に複数のファイルタブが開いており、選択中のファイルタブに中身が表示されている
WHEN 利用者が、同じ pane の別のファイルタブを選ぶ
THEN アプリは、選択を外れたファイルタブの中身を破棄する
