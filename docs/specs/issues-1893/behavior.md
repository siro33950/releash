## B-001: store の問い合わせが呼び出しの期限で終わる

GIVEN 期限の付いた呼び出しが store への問い合わせを行う
WHEN その問い合わせが呼び出しの期限までに終わらない
THEN その問い合わせは呼び出しの期限を超えて続かない
AND 呼び出しは `DEADLINE_EXCEEDED` で終わる

## B-002: 外部プロセスの実行が呼び出しの期限で終わる

GIVEN 期限の付いた呼び出しが外部プロセス（`git`、`gh` など）を起動する
WHEN そのプロセスが呼び出しの期限までに終わらない
THEN そのプロセスは終了する
AND 呼び出しは `DEADLINE_EXCEEDED` で終わる

## B-003: lock の待ちが呼び出しの期限で終わる

GIVEN 期限の付いた呼び出しが、ほかの処理が保持する lock を待つ
WHEN 呼び出しの期限までに lock を取得できない
THEN その待ちは呼び出しの期限を超えて続かない
AND 呼び出しは `DEADLINE_EXCEEDED` で終わる

## B-004: 中断が同期処理の内側へ届く

GIVEN 呼び出しが store の問い合わせ、外部プロセスの実行、または lock の待ちを実行している
WHEN client がその呼び出しをやめる
THEN その処理は実行中の操作を中断して止まる
AND 呼び出しは `CANCELLED` で終わる

## B-005: 止まった処理が外部プロセスとファイルの lock を残さない

GIVEN 呼び出しから始まった処理が、外部プロセスまたはファイルの lock を確保している
WHEN その処理が引き継いだ期限の超過または取り消しで止まる
THEN その外部プロセスは終了する
AND そのファイルの lock は解放される

## B-006: 処理の先が持つ期限の方が早いとき、そちらで終わる

GIVEN 呼び出しの期限が、その処理の先が持つ期限より後に来る
WHEN その処理が、処理の先が持つ期限までに終わらない
THEN その処理はその期限を超えて続かない
AND 呼び出しは `DEADLINE_EXCEEDED` で終わる

## B-007: 期限が引き継がれない経路では処理の先の期限が上限になる

GIVEN 呼び出しの期限が引き継がれない経路が、store の問い合わせ、外部プロセスの実行、または lock の待ちを行う
WHEN その処理が、処理の先が持つ期限までに終わらない
THEN その処理はその期限を超えて続かない

## B-008: 受け付けられた書き込みは呼び出しが終わっても保存される

GIVEN 呼び出しから始まった書き込みが store の待ち行列へ受け付けられている
WHEN その呼び出しが期限切れまたは中断で終わる
THEN その書き込みは保存される

## B-009: 中断できない操作は、その操作が終わった時点で止まる

GIVEN 呼び出しから始まった処理が、中断できない操作を実行している
WHEN その呼び出しが期限切れまたは中断で終わる
THEN その処理は実行中の操作が終わった時点で止まる
AND 次の操作へ進まない
