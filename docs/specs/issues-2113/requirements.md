# Context

- 要求の正本は、ISSUE #2113「Swift.app: Workspaces のサイドバーを整理し、変更の数を Source Control のアイコンに移す」の本文と、本文に貼られた参考 mock の画像（<https://github.com/user-attachments/assets/97b36933-a376-47e1-98df-5b8e1e5c124f>）である。
- 調査の時点は main `373fb61b` である。
- サイドバーは、リポジトリごとの区切りの中に、worktree のカードを並べる。カードは、worktree のブランチ名と、その worktree で動いている実行（Session と Workflow）を出す。
- 右カラムの上部には、Node、ファイル、Source Control、Thread の 4 つの面を切り替えるアイコンが並ぶ。
- 画面のアイコンは、ISSUE #2111 で Lucide に揃えた。その仕様は `docs/specs/issues-2111/` が持つ。
- 実行の状態の 3 値（attention、active、idle）と色の仕様は `docs/specs/issues-1958/` が持つ。
- PR の状態は、open、draft、merged、closed の 4 つである。closed は、マージされずに閉じられた PR を指す。
- ISSUE は、完了条件として、回帰の E2E がサイドバーのボタンやカードの文言を探している箇所を新しい配置に合わせること、手元で確認した証跡を PR に貼ることを挙げている。

# Outcome

対象者は、Swift.app で複数の worktree の Workflow と Session を観測する開発者である。

今のサイドバーは、worktree のカードが、PR の状態、変更の数、取得失敗のエラー文、Workflow の状態の四角に、それぞれ 1 行を使う。
カードが縦に長くなり、一度に見える worktree の数が減る。
上端の見出しと 3 つのボタンの行も、一覧の高さを 1 行分減らしている。

変更後は、PR の状態と取得失敗が、カードの 1 行目の右端の印に収まる。
カードの高さは、実行が無いときは 2 行分になり、実行があるときはブランチ名の 1 行と実行の数だけの行になる。
削除している途中の worktree のカードだけ、「削除中」の 1 行が加わる。
変更の数は、右カラムの Source Control の切り替えアイコンのバッジで、選んでいる worktree の分だけを見る。

## 上端と下端

- サイドバーの上端には、ウィンドウの操作ボタンと同じ高さの空の帯がある。その下に、「Workspaces」の見出しと、リポジトリを追加、再読み込み、Worktree を作成の 3 つのボタンを並べた行がある。
- サイドバーの下端にフッターは無い。worktree の一覧がサイドバーの下端まで続く。

## リポジトリの区切り

- 見出しは、リポジトリのフォルダ名と、worktree の数を出す。
- リポジトリの取得に失敗したときは、区切りの中の先頭に、エラー文を 1 行で出す。

## worktree のカード

- 1 行目は、アイコンとブランチ名である。アイコンは、main の worktree が `house`、ブランチの worktree が `git-branch` である。
- 次のどれかに当たるとき、1 行を使って、当たるものを横に並べる。
  - マージ済みのブランチには、Merged の印（`circle-check`）を出す。
  - 変更の数が 1 以上のとき、「N changes」を出す。0 のときは出さない。
  - 削除している途中の worktree には、進行中の印と「削除中」の文字を出す。
- PR があるブランチには、1 行を使って、PR の状態のアイコンを出す。
  - アイコンは、open が `git-pull-request`、draft が `git-pull-request-draft`、merged が `git-merge`、closed が `git-pull-request-closed` である。
  - 色は、4 つとも副次的な文字の色（灰色）である。
  - マウスを乗せると、「PR #番号: 状態」を出す。
- 取得に失敗したときは、失敗 1 つにつき 1 行を使う。
  - 変更の数の取得失敗は「Changes unavailable」、PR の取得失敗は「PR unavailable」を出す。エラー文は、マウスを乗せたときに出す。
  - worktree のエラーは、エラー文をそのまま出す。
  - この 3 つは、同じカードで重なる。
  - PR の取得に失敗すると、同じリポジトリの全部の worktree のカードに「PR unavailable」が出る。
- 動いている実行を、1 つずつ並べる。
  - Session の行は、`bot` のアイコン、provider 名（Claude、Codex）、タイトルを出す。provider 名は中太である。
  - Workflow の行は、`waypoints` のアイコンと「名前 · N nodes」を出す。文字は全部、副次的な文字の色（灰色）である。その下に、Session の状態の色の四角を並べる。
  - どちらの行も、アイコンは実行の状態の色である。
- 実行が無く、上のどの表示にも当たらない worktree のカードは、1 行目だけの高さになる。

## Source Control の切り替えアイコン

- 右カラムの上部の切り替えアイコンは、Node（`list`）、ファイル（`file`）、Source Control（`git-branch`）、Thread（`message-square`）の順に並ぶ。
- 切り替えアイコンは、右カラムを開いているときだけ出る。
- Source Control の切り替えアイコンに、数は出ない。

# Requirements

## 上端と下端

- R-001: サイドバーに「Workspaces」の見出しが出ない。サイドバーの上端に出るボタンは、「Worktreeを作成」の 1 つだけである。参考 mock のとおり、このボタンは、ウィンドウの操作ボタンと同じ高さの帯の右端に出る。
- R-002: サイドバーの下端にフッターが出る。フッターには、リポジトリを追加するボタンと「更新」のボタンの 2 つが、右寄せで並ぶ。開発者が「更新」のボタンを押すと、worktree の一覧が、読み込み直した内容で出る。

## リポジトリの見出し

- R-003: リポジトリの取得に失敗したとき、リポジトリの見出しの右端に、警告の印（`triangle-alert`）が出る。開発者が印にマウスを乗せると、エラー文が出る。リポジトリのエラーのための行は出ない。

## worktree のカード

- R-004: PR があるブランチのカードは、1 行目の右端に、PR の状態のアイコンを出す。PR の状態のための行は出ない。
- R-005: PR の状態のアイコンは、状態ごとの色で出る。open は緑、draft は灰、merged は紫、closed は赤である。
- R-006: カードに Merged の印（`circle-check`）が出ない。
- R-007: カードに変更の数（「N changes」）が出ない。
- R-008: 変更の数の取得失敗、PR の取得失敗、worktree のエラーのどれか 1 つ以上があるカードは、1 行目の右端に、警告の印（`triangle-alert`）を 1 つ出す。失敗が 2 つ以上重なっても、印は 1 つである。取得失敗のための行は出ない。
- R-009: 開発者がカードの警告の印にマウスを乗せると、そのカードで失敗している項目が全部出る。変更の数の取得失敗は「Changes unavailable」とエラー文、PR の取得失敗は「PR unavailable」とエラー文、worktree のエラーはエラー文で出る。
- R-010: PR の状態のアイコンと警告の印が同じカードに揃うとき、両方が 1 行目の右端に並ぶ。
- R-011: Session の行は、アイコンとタイトルを出す。provider 名（Claude、Codex）の文字は出ない。
- R-012: Workflow の行は、アイコン、名前、「· N nodes」を出す。名前は、Session の行のタイトルと同じ文字色、同じ大きさで出る。「· N nodes」は灰色で出る。Session の状態の四角の並びは出ない。
- R-013: カードは、最低 2 行分の高さで出る。実行が無く、削除している途中でもない worktree のカードは、2 行目が空である。
- R-014: 削除している途中の worktree のカードは、2 行目に、進行中の印と「削除中」の文字を出す。その worktree に実行があるとき、実行の行は「削除中」の行の下に並ぶ。

## 変更の数

- R-015: 選んでいる worktree の変更の数が 1 以上のとき、右カラムの上部の Source Control の切り替えアイコンに、その数が灰色の丸いバッジで重なる。参考 mock のとおり、バッジはアイコンの右上に出る。
- R-016: 変更の数が 99 を超えるとき、バッジは「99+」と出る。
- R-017: 変更の数が 0 のとき、変更の数を取得できなかったとき、worktree を選んでいないとき、バッジは出ない。

## アイコン

- R-018: この変更で足す・動かすアイコンは、Lucide のアイコンで出る。
