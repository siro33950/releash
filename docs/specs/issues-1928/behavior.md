## B-001: 包みの定義の所在

期限・取り消し・やり直し・計測の包みの定義は `common` にある。`common` は他のどの層も参照しない。

## B-002: 包みが掛かる位置

取り消しは受け手の側（controller の手前）で包みとして掛かる。期限は受け手の側と出ていく側（adaptor/gateway と infrastructure）で包みとして掛かる。一時的な失敗のやり直しは出ていく側で包みとして掛かる。計測の包みは、受け手の側・Usecase の入口・出ていく側以外の位置には掛かっていない。これらは処理の中に書かれていない。

## B-015: 一時的な失敗のやり直しは gateway の中で閉じる

GIVEN 外部世界への呼び出しが一時的な失敗をする
WHEN 出ていく側の包みがその呼び出しをやり直す
THEN やり直しは gateway の中で終わり、内側へは結果だけが返る

## B-003: domain は期限・取り消し・やり直しを受け取らない

domain の型・失敗・trait は、期限・取り消し・やり直しを表す値を持たない。domain は `common` を参照しない。

## B-004: usecase は期限・取り消し・やり直しを受け取らない

usecase の Usecase・Input Data・Output Data・trait は、期限・取り消し・やり直しを表す値を持たない。繰り返し処理を回す作業列と、そこへ仕事を積む経路はこの判定の対象に入らず、作業列が #1930 で usecase から出るときに対象へ入る。

## B-005: 版の競合で手順をやり直すかは usecase が決める

GIVEN 業務の手順の途中で集約の版の競合が起きる
WHEN その手順を実行している Usecase が、手順をやり直すと決める
THEN その手順は、集約を読み直した上の段階からやり直される

## B-006: other/ の不在

`src-tauri/src/other/` は存在しない。そこにあった各部品は、規約の部品の一覧のいずれかの部品として置かれている。

## B-007: 期限切れで終わった呼び出しの結果

GIVEN 期限の付いた呼び出しが実行されている
WHEN その呼び出しが期限までに終わらない
THEN その呼び出しは `DEADLINE_EXCEEDED` で終わる

## B-008: 中断で終わった呼び出しの結果

GIVEN 呼び出しが実行されている
WHEN client がその呼び出しをやめる
THEN その呼び出しは `CANCELLED` で終わる

## B-017: 出ていく側の自前の期限切れの結果

GIVEN 呼び出しの中で、外部世界への呼び出しに、呼び出し自体の期限より短い期限が掛かっている
WHEN その短い期限が切れる
THEN その呼び出しは、包み化の前と同じ結果で終わる

## B-009: 期限と取り消しの処理の先への引き継ぎ

GIVEN 期限の付いた呼び出しが、store の問い合わせ、外部プロセスの実行、または lock の待ちを行う
WHEN その処理が呼び出しの期限までに終わらない、または client がその呼び出しをやめる
THEN その処理は呼び出しの期限を超えて続かず、取り消しを受けて止まる

## B-010: 止まった処理の後始末

GIVEN 呼び出しから始まった処理が、外部プロセスまたはファイルの lock を確保している
WHEN その処理が期限切れまたは取り消しで止まる
THEN その外部プロセスは終了する
AND そのファイルの lock は解放される

## B-011: やり直しの待ち時間と回数の上限

GIVEN daemon の中で繰り返す処理が、やり直す分類の失敗をする
WHEN その処理がやり直される
THEN やり直しの待ち時間は、包み化の前と同じ決まり方で決まる
AND daemon が行うやり直しは、単位時間あたりの回数の上限を超えない

## B-012: 失敗の記録と要対応の表示

GIVEN 対象が、やり直さない分類のうち意図して止めたことを表す分類を除く分類で失敗する
WHEN 利用者がその対象の表示と失敗の記録を見る
THEN その対象が「要対応」であることを観測できる
AND 同じ処理の種類・対象・失敗の分類の失敗は 1 件の記録にまとまり、発生回数と最初・最後の時刻を持つ

## B-013: 計測の項目と値の意味

計測の項目と、計測した値の意味は、包み化の前と変わらない。

## B-016: 性能計測の sample の記録点の呼び先

usecase の性能計測の sample の記録点は、Output Boundary の trait を通る。gateway の記録点は、infrastructure の計測の仕組みを使う。usecase は計測の実装を参照しない。

## B-014: 使われなくなるコードの不在

この変更で使われなくなったコードは残らない。
