## B-001: 開始ごとに新しい識別子を付ける

GIVEN 画面が daemon への stream を開いている
WHEN 画面がある対象の購読を開始し、その後、再接続または terminal の開始し直しで同じ対象の購読を開始し直す
THEN 各開始の要求は、識別子と対象の名前・引数を持つ
AND 開始し直しの要求の識別子は、前の開始の識別子と異なる

## B-002: 届く値は識別子で購読を指す

GIVEN 画面が識別子を付けて購読を開始している
WHEN daemon がその購読の snapshot・change・failure・購読ごとの bookmark を送る
THEN 届く値はその識別子を持つ
AND 届く値は対象の名前と引数を持たない

## B-003: stream 全体の合図は識別子を持たない

GIVEN 画面が daemon への stream を開いている
WHEN daemon が ready または stream の bookmark を送る
THEN その合図は識別子を持たない

## B-004: 届いた値を識別子で引き当てる

GIVEN 画面が 2 つの異なる対象を、それぞれ別の識別子で購読している
WHEN 片方の識別子を持つ値が届く
THEN その値は、その識別子の購読の受け手にだけ渡る

## B-005: 停止は識別子だけで購読を指す

GIVEN 画面が識別子を付けて購読を開始している
WHEN 画面がその購読を停止する
THEN 停止の要求は識別子だけで購読を指す
AND その識別子の値はそれ以降届かない

## B-006: 知らない識別子の停止は成功する

GIVEN daemon がある識別子の有効な購読を持っていない
WHEN その識別子の停止の要求が届く
THEN 停止の要求は成功する
AND 他の購読は変わらない

## B-007: 形の誤った識別子の開始を拒む

GIVEN 画面が daemon への stream を開いている
WHEN 空の識別子、または 128 バイトを超える識別子で開始の要求が届く
THEN 開始の要求は INVALID_ARGUMENT で拒まれる

## B-008: 重なる識別子の開始を拒む

GIVEN ある client が識別子 X で購読している
WHEN 同じ client または別の client から、識別子 X で開始の要求が届く
THEN 開始の要求は ALREADY_EXISTS で拒まれる
AND 既存の識別子 X の購読には値が届き続ける
AND 開始を送った client の stream は閉じない

## B-009: 無効になった識別子は再び使える

GIVEN 識別子 X の購読が、停止・切断・stream の終了のどれかで無効になっている
WHEN 識別子 X で開始の要求が届く
THEN 開始の要求は受け付けられる

## B-010: 同時に来た同じ識別子の開始

GIVEN 識別子 X の有効な購読が無い
WHEN 識別子 X を持つ 2 つの開始の要求が同時に届く
THEN 受け付けられるのは多くとも 1 つである

## B-011: 同じ対象を指す複数の購読

GIVEN 同じ client が、ラベルの絞り込みの並び順だけが違う 2 つの Notion のタスクの一覧の購読を、別々の識別子で開始している
WHEN daemon がその対象の値を取得して送る
THEN Notion からの取得は 1 回である
AND 値は 2 つの識別子のそれぞれに届く

## B-012: 片方の停止で他方が外れない

GIVEN 同じ正規化した対象を、識別子 X と識別子 Y の 2 つの購読が指している
WHEN 識別子 X の購読を停止する
THEN 識別子 Y の購読には、その後の値が届き続ける

## B-013: 片方の停止で他方の terminal の出力が止まらない

GIVEN 同じ client が、同じ terminal を識別子 X と識別子 Y の 2 つで購読している
WHEN 識別子 X の購読を停止する
THEN 識別子 Y の購読には、その terminal の出力が届き続ける

## B-014: 開始が終わる前の停止

GIVEN 画面が購読の開始の要求を送り、その要求がまだ終わっていない
WHEN その購読の受け手がいなくなる
THEN 画面は開始の要求が終わってから停止の要求を送る
AND daemon にその購読は残らない

## B-015: terminal の入力の宛先は購読の識別子

GIVEN 画面が識別子 X で terminal の購読を開始し、受け付けられている
AND その terminal で X より後に開始された購読は無い
WHEN 画面がその terminal へ宛先 X で入力を送る
THEN 入力は受理される

GIVEN 識別子 X で terminal の購読を開始した後、同じ terminal を識別子 Y で購読を開始した
WHEN 宛先 X で入力を送る
THEN X の購読が続いていても、入力は受理されない（入力の宛先は最後に開始した Y に置き換わっている）

## B-016: 処理済みの量の報告は識別子で購読を指す

GIVEN 画面が識別子 X で terminal の購読をしている
WHEN 画面が処理済みの量を報告する
THEN 報告の要求は識別子 X と量だけを持つ
AND 報告は受理される

## B-017: terminal の購読を指さない報告

GIVEN 識別子 X が、有効な terminal の購読を指していない
WHEN 識別子 X で処理済みの量の報告が届く
THEN 報告は、terminal の購読が無いときと同じ失敗で拒まれる
