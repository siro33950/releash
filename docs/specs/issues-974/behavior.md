## Behavior

本移行は純粋リファクタリングであり、外部から観測可能な振る舞いを一切変えない。
したがって振る舞い定義は、`code` ドメインの各責務についてアクターが観測する結果が
移行前後で等価であること（振る舞いの保持）を不変条件として表現する。

```gherkin
Feature: code ドメインの振る舞い保持

  Rule: ファイル内容の参照結果は移行前後で等価である
    Scenario: 特定のコミット時点のファイル内容を参照する
      Given 利用者が編集中のリポジトリと参照したいコミット時点を選んでいる
      When 利用者がそのコミット時点でのファイル内容を要求する
      Then 移行前と同じファイル内容が返る

    Scenario: ブランチ分岐点のファイル内容を参照する
      Given 利用者がブランチとその分岐元を選んでいる
      When 利用者が分岐点時点でのファイル内容を要求する
      Then 移行前と同じファイル内容が返る

    Scenario: ステージ済みのファイル内容を参照する
      Given 利用者が変更をステージ済みのファイルを選んでいる
      When 利用者がステージ済みのファイル内容を要求する
      Then 移行前と同じファイル内容が返る

  Rule: 差分の閲覧結果は移行前後で等価である
    Scenario: ファイルの差分を閲覧する
      Given 利用者が変更のあるファイルを選んでいる
      When 利用者がそのファイルの差分を要求する
      Then 移行前と同じ差分が返る

    Scenario: 変更されたファイル一覧を閲覧する
      Given 利用者が変更を含む作業状態にいる
      When 利用者が変更されたファイルの一覧を要求する
      Then 移行前と同じファイル一覧が返る

    Scenario: ブランチ間の差分を閲覧する
      Given 利用者が比較したい二つのブランチ状態を選んでいる
      When 利用者がブランチ間の差分を要求する
      Then 移行前と同じ差分が返る

  Rule: 差分の部分単位の取り扱いは移行前後で等価である
    Scenario: 差分を変更の塊単位で取得する
      Given 利用者が差分を持つファイルを選んでいる
      When 利用者が差分を変更の塊単位で要求する
      Then 移行前と同じ塊の区切りと内容が返る

    Scenario: 差分から適用用のパッチを得る
      Given 利用者が差分を持つファイルを選んでいる
      When 利用者がその差分に対応するパッチを要求する
      Then 移行前と同じパッチが返る

  Rule: 差分の Approve（ステージング）結果は移行前後で等価である
    Scenario: 差分の一部を Approve する
      Given 利用者が未ステージの差分を持つファイルを選んでいる
      When 利用者が差分の一部を Approve する
      Then 移行前と同じ範囲がステージ済みになる

  Rule: 言語判定の結果は移行前後で等価である
    Scenario: ファイルの言語を判定する
      Given 利用者がファイルを選んでいる
      When 利用者がそのファイルの言語判定を要求する
      Then 移行前と同じ言語が返る

  Rule: ファイルメンション補完の結果は移行前後で等価である
    Scenario: メンション対象のファイルを補完する
      Given 利用者がファイルメンションの入力途中の状態にいる
      When 利用者が入力に対するメンション候補を要求する
      Then 移行前と同じ候補が返る

  Rule: 表示／非表示範囲の算出結果は移行前後で等価である
    Scenario: 差分の表示範囲と非表示範囲を算出する
      Given 利用者が差分を持つファイルを表示している
      When 利用者が表示範囲と非表示範囲を要求する
      Then 移行前と同じ表示範囲・非表示範囲が返る

  Rule: リモートクライアントから見た振る舞いも移行前後で等価である
    Scenario: リモートクライアントが diff 閲覧・ソース管理を行う
      Given リモートクライアントの利用者が遠隔接続で作業状態を参照している
      When 利用者が diff 閲覧やソース管理の操作を行う
      Then 移行前と同じ結果が返る
```
