# Behavior

対象 Issue: #1193「Agent: 新規セッション初回ターンで普通の指示が「モデルを設定しました」とだけ返ることがある」

この文書は requirements.md の要求を、実装詳細を含まない観測可能な振る舞いとして Gherkin で定義する。観測の主体はユーザー（Agent セッションを操作する人）であり、内部のコマンド経路（init コマンド・set_model control request 等）は振る舞いの記述対象にしない。

## 仮定

- 仮定A: 「初回ターン」とは、新規 Agent セッションを開始してから最初にユーザーがメッセージを送って得られる 1 回のターンを指す。
- 仮定B: 「普通の指示テキスト」とは、`/model` 等のスラッシュコマンドではない通常の自然言語の指示を指す。
- 仮定C: 「モデル変更のみの定型応答」とは、ユーザー指示に対する作業を伴わず、モデル設定の旨だけを述べて指示内容に応答しない発話（例:「モデルを設定しました。まだ具体的な指示をいただいていません。何を行いましょうか？」）を指す。
- 仮定D: 本件の最終的な不具合解消の確証は CLI 内部挙動が非公開のため実機ビルドでの再現確認に依存する（requirements 仮定D）。本文書のシナリオは、その実機確認で満たされるべき外部観測可能な期待を定義する。
- 仮定E: 「セッション実行中のモデル変更」とは、セッションを開始済みのプロセスが生存している状態で、ユーザーがモデルを別のモデルへ切り替える操作を指す。

## Feature: 新規セッション初回ターンでのユーザー指示の確実な実行

Agent セッションでは、ユーザーが送った指示は初回ターンでも確実に実行され、
モデル設定の都合でユーザー指示が定型応答に化けることがない。

  Background:
    Given Agent バックエンドが利用可能である
    And セッションで使用するモデルが解決可能である

  Rule: 新規セッション初回ターンの普通の指示は、モデル変更のみの定型応答に化けない

    Scenario: 初回ターンで普通の指示を送ると指示が実行される
      Given 新規 Agent セッションを開始する
      When ユーザーが初回ターンで普通の指示テキストを送る
      Then その指示がそのターンで実行される
      And モデル変更のみの定型応答が単独で返らない

    Scenario: 初回ターンの指示が複数回の試行でも安定して実行される
      Given 新規 Agent セッションを開始する
      When ユーザーが初回ターンで普通の指示テキストを送る試行を複数回繰り返す
      Then いずれの試行でも指示がそのターンで実行される
      And いずれの試行でもモデル変更のみの定型応答が単独で返らない

    Scenario: 初回ターンで使われるモデルは開始時に意図したモデルである
      Given 新規 Agent セッションを開始する
      When ユーザーが初回ターンで普通の指示テキストを送る
      Then 当該ターンの応答は意図したモデルで生成される

  Rule: セッション実行中のモデル変更は以降のターンへ反映される

    Scenario: 実行中にモデルを切り替えると次のターンで切り替え後のモデルが使われる
      Given 実行中の Agent セッションがある
      When ユーザーがモデルを別のモデルへ切り替える
      And その後ユーザーが指示テキストを送る
      Then 切り替え後のモデルで応答が生成される

  Rule: resume したセッションでも意図したモデルで指示が正しく実行される

    Scenario: resume 直後の初回ターンで指示が実行される
      Given 以前のセッションを resume する
      When ユーザーが resume 後の初回ターンで普通の指示テキストを送る
      Then その指示がそのターンで意図したモデルで実行される
      And モデル変更のみの定型応答が単独で返らない

    Scenario: resume 後の 2 ターン目以降も通常どおり送受信できる
      Given 以前のセッションを resume し初回ターンを完了している
      When ユーザーが続けて指示テキストを送る
      Then 各ターンで指示が意図したモデルで正しく実行される

  Rule: 2 ターン目以降の通常の送受信に回帰がない

    Scenario Outline: 新規セッションの 2 ターン目以降でも指示が正しく実行される
      Given 新規 Agent セッションで初回ターンを完了している
      When ユーザーが <turn> 回目のターンで指示テキストを送る
      Then その指示がそのターンで実行される
      And モデル変更のみの定型応答が単独で返らない

      Examples:
        | turn |
        | 2    |
        | 3    |
