# Behavior

## Source
- requirements.md

## Behavior

```gherkin
Feature: agent_session 移行後の Agent セッション基本機能の維持

  Rule: Agent セッションを起動できる
    Scenario: デスクトップのエンドユーザーがセッションを起動する
      Given Agent セッションがまだ開始されていない作業対象がある
      When エンドユーザーがデスクトップから Agent セッションの起動を指示する
      Then Agent セッションが開始され、対話・操作が可能な状態になる

    Scenario: リモートクライアントがセッションを起動する
      Given Agent セッションがまだ開始されていない作業対象がある
      When リモートクライアントが Agent セッションの起動を要求する
      Then Agent セッションが開始され、リモートから対話・操作が可能な状態になる

  Rule: Agent セッションを停止できる
    Scenario: エンドユーザーがセッションを停止する
      Given 起動済みの Agent セッションがある
      When エンドユーザーがデスクトップから Agent セッションの停止を指示する
      Then Agent セッションが終了し、対話・操作ができない状態になる

  Rule: Agent セッションの状態を確認できる
    Scenario: エンドユーザーがセッションの状態を確認する
      Given 1 つ以上の Agent セッションがある
      When エンドユーザーがデスクトップからセッションの状態を問い合わせる
      Then 各セッションの実行状態（実行中・完了・エラー・待機など）が得られる

    Scenario: リモートクライアントがセッションの状態変化を受け取る
      Given リモートクライアントが接続している
      When Agent セッションの状態が変化する
      Then リモートクライアントに最新のセッション状態が配信される

  Rule: Agent セッションの出力がブロードキャストされる
    Scenario: エンドユーザーが実行中の出力を受け取る
      Given 起動済みの Agent セッションが応答を生成している
      When Agent が出力を生成する
      Then エンドユーザーの画面に出力が逐次反映される

    Scenario: リモートクライアントが実行中の出力を受け取る
      Given 起動済みの Agent セッションが応答を生成している
      And リモートクライアントが接続している
      When Agent が出力を生成する
      Then 接続中のリモートクライアントに出力が配信される

  Rule: Agent にメッセージを送信できる
    Scenario: エンドユーザーがメッセージを送信する
      Given 起動済みの Agent セッションがある
      When エンドユーザーがデスクトップから Agent にメッセージを送信する
      Then Agent がメッセージを受け取り、応答の生成を開始する

    Scenario: リモートクライアントがメッセージを送信する
      Given 起動済みの Agent セッションがある
      When リモートクライアントが Agent にメッセージを送信する
      Then Agent がメッセージを受け取り、応答の生成を開始する

  Rule: 実行中の Agent を中断できる
    Scenario: エンドユーザーが実行中の Agent を中断する
      Given Agent が応答を生成している
      When エンドユーザーがデスクトップから中断を指示する
      Then 実行中の処理が中断され、セッションは次の指示を受け付けられる状態になる

    Scenario: リモートクライアントが実行中の Agent を中断する
      Given Agent が応答を生成している
      When リモートクライアントが中断を要求する
      Then 実行中の処理が中断され、セッションは次の指示を受け付けられる状態になる

  Rule: Agent セッションの使用モデルを変更できる
    Scenario: エンドユーザーが使用モデルを変更する
      Given 起動済みの Agent セッションがある
      When エンドユーザーがデスクトップからセッションの使用モデルを変更する
      Then 以降のやり取りが変更後のモデルで行われる

    Scenario: リモートクライアントが使用モデルを変更する
      Given 起動済みの Agent セッションがある
      When リモートクライアントがセッションの使用モデルを変更する
      Then 以降のやり取りが変更後のモデルで行われる

  Rule: Agent セッションの権限モードを変更できる
    Scenario: エンドユーザーが権限モードを変更する
      Given 起動済みの Agent セッションがある
      When エンドユーザーがデスクトップからセッションの権限モードを変更する
      Then 以降の権限要求の扱いが変更後の権限モードに従う

    Scenario: リモートクライアントが権限モードを変更する
      Given 起動済みの Agent セッションがある
      When リモートクライアントがセッションの権限モードを変更する
      Then 以降の権限要求の扱いが変更後の権限モードに従う
```
