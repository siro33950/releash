# Behavior

## Source
- requirements.md

## 仮定

本移行はレイヤー構成の再配置であり、外部から観測できる基本機能は維持される（requirements「Goal」「Requirements」）。本書はその維持される振る舞いを定義し、レイヤー配置・モジュール除去・DI 配線などの内部構造要件は実装仕様（design.md）側の関心として Gherkin には含めない。

- 設定（`app_config`）の参照／更新の主入口はデスクトップのエンドユーザー（Tauri コマンド）である。リモートクライアント／外部 MCP クライアントは、永続化された設定値（サーバポート・接続トークン等）を介して間接的に影響を受ける。
- MCP サーバの起動／停止／状態取得の主入口はデスクトップのエンドユーザーである。外部 MCP クライアントが観測するのは、サーバへの接続可否・認証・提供ツールである。
- 「設定が永続化される」とは、更新後にアプリを再起動しても同じ値が読み戻せることを指す（TOML 設定ファイルへの保存）。
- requirements「重複実装の整理等の移行作業に伴ってユーザー側の振る舞いに多少の変更が生じることは許容する」に従い、本書は応答の細部ではなく観測可能なビジネスルールの維持を定義する。

## Behavior

```gherkin
Feature: app_config 移行後の設定機能の維持

  Background:
    Given Releash デスクトップアプリが起動している
    And アプリ設定が TOML 設定ファイルに永続化される構成になっている

  Rule: 設定値を参照できる
    Scenario Outline: エンドユーザーが各設定区分の現在値を取得する
      Given アプリ設定に <区分> の値が保持されている
      When エンドユーザーがデスクトップから <区分> の設定値を要求する
      Then 現在保持されている <区分> の設定値が得られる

      Examples:
        | 区分             |
        | サーバ           |
        | MCP              |
        | アプリ全般        |
        | リモート          |
        | ワークフロー      |
        | テレメトリ        |
        | クラッシュレポート |

  Rule: 設定値を更新でき、更新は永続化される
    Scenario Outline: エンドユーザーが設定値を更新する
      Given アプリ設定に <区分> の現在値が保持されている
      When エンドユーザーがデスクトップから <区分> の設定値を新しい値に更新する
      Then 以降の参照で新しい値が得られる
      And アプリを再起動しても新しい値が読み戻せる

      Examples:
        | 区分             |
        | サーバポート      |
        | MCP              |
        | アプリ全般        |
        | リモート          |
        | ワークフロー      |
        | テレメトリ        |
        | クラッシュレポート |
        | 最終サーバ接続情報 |

  Rule: 接続トークンを再生成できる
    Scenario: エンドユーザーがサーバ接続トークンを再生成する
      Given サーバ接続トークンが保持されている
      When エンドユーザーがデスクトップからサーバ接続トークンの再生成を指示する
      Then 旧トークンとは異なる新しいトークンが生成される
      And 新しいトークンが永続化される

    Scenario: エンドユーザーが MCP 接続トークンを再生成する
      Given MCP 接続トークンが保持されている
      When エンドユーザーがデスクトップから MCP 接続トークンの再生成を指示する
      Then 旧トークンとは異なる新しいトークンが生成される
      And 新しいトークンが永続化される

  Rule: 設定ファイルが存在しない場合でも設定を利用できる
    Scenario: 設定ファイルがまだ存在しない状態でアプリが起動する
      Given 設定ファイルが存在しない
      When エンドユーザーが設定値を要求する
      Then 既定値に基づく設定値が得られる
      And 以降の更新が新たに作成された設定ファイルへ永続化される

  Rule: 永続化された設定値が他クライアントの接続条件に反映される
    Scenario: リモートクライアントが更新後のサーバ設定で接続する
      Given エンドユーザーがサーバポートまたは接続トークンを更新済みである
      When リモートクライアントが接続を試みる
      Then 更新後のポート・トークンに整合した接続のみが成立する

Feature: mcp 移行後の MCP サーバ機能の維持

  Background:
    Given Releash デスクトップアプリが起動している

  Rule: MCP サーバを起動できる
    Scenario: エンドユーザーが MCP サーバを起動する
      Given MCP サーバが起動していない
      When エンドユーザーがデスクトップから MCP サーバの起動を指示する
      Then MCP サーバが起動し、外部 MCP クライアントが接続可能な状態になる
      And 接続に必要な接続情報（エンドポイント等）が得られる

  Rule: MCP サーバを停止できる
    Scenario: エンドユーザーが MCP サーバを停止する
      Given MCP サーバが起動している
      When エンドユーザーがデスクトップから MCP サーバの停止を指示する
      Then MCP サーバが停止し、外部 MCP クライアントから接続できない状態になる

  Rule: MCP サーバの状態を確認できる
    Scenario: エンドユーザーが起動中のサーバ状態を確認する
      Given MCP サーバが起動している
      When エンドユーザーがデスクトップから MCP サーバの状態を問い合わせる
      Then 起動中であることと接続情報が得られる

    Scenario: エンドユーザーが停止中のサーバ状態を確認する
      Given MCP サーバが起動していない
      When エンドユーザーがデスクトップから MCP サーバの状態を問い合わせる
      Then 停止中であることが得られる

  Rule: 外部 MCP クライアントへ認証付きでツールを提供する
    Scenario: 正当なトークンを持つクライアントが接続する
      Given MCP サーバが起動している
      And クライアントが有効な接続トークンを提示する
      When クライアントが MCP サーバへ接続しツール一覧を要求する
      Then 接続が許可され、提供ツールの一覧が得られる

    Scenario: トークンを持たない／不正なクライアントが接続する
      Given MCP サーバが起動している
      When 有効な接続トークンを提示しないクライアントが MCP サーバへ接続を試みる
      Then 接続が拒否される

  Rule: 外部エージェント向け MCP 設定を生成・管理できる
    Scenario: エンドユーザーが対象エージェントの MCP 設定を生成・保存する
      Given 外部エージェント向けの MCP 設定生成が要求される
      When エンドユーザーがデスクトップから対象エージェントを選択して設定生成を指示する
      Then 対象エージェント用の MCP 設定が生成・保存される

    Scenario: エンドユーザーが生成前に MCP 設定内容を確認する
      Given 外部エージェント向けの MCP 設定生成が要求される
      When エンドユーザーがデスクトップから生成内容のプレビューを要求する
      Then 保存される MCP 設定の内容が得られる

    Scenario: エンドユーザーが既に設定済みのエージェント一覧を取得する
      Given 1 つ以上のエージェントに MCP 設定が保存されている
      When エンドユーザーがデスクトップから設定済みエージェントの一覧を要求する
      Then 設定済みエージェントの一覧が得られる

    Scenario: エンドユーザーがエージェントの MCP 設定を削除する
      Given あるエージェントに MCP 設定が保存されている
      When エンドユーザーがデスクトップからそのエージェントの MCP 設定削除を指示する
      Then 該当エージェントの MCP 設定が除去される
```
