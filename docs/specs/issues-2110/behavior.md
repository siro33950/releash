## B-001: 「ファイル」の面の構成

GIVEN 利用者が worktree を選んでいる
WHEN 利用者が右カラムで「ファイル」の面を選ぶ
THEN 右カラムの左にファイル一覧、右にファイルタブの領域が出る

## B-002: ファイル一覧からファイルを開く

GIVEN 利用者が右カラムの「ファイル」の面を開いていて、ファイルタブを一つも開いていない
WHEN 利用者がファイル一覧のファイルの行を押す
THEN 同じ「ファイル」の面のファイルタブの領域に、そのファイルのタブと本文が出る
AND 中央の pane のタブは増えない

## B-003: 開いているファイルをもう一度押す

GIVEN ファイルタブの領域に、あるファイルのタブと別のファイルのタブがあり、別のファイルのタブが選ばれている
WHEN 利用者がファイル一覧で、すでにタブのあるファイルの行を押す
THEN タブの数は変わらず、そのファイルのタブが選ばれる

## B-004: ファイルタブの領域の分割

GIVEN ファイルタブの領域に二つのファイルタブがある
WHEN 利用者が一方のタブを領域の端へドラッグする
THEN ファイルタブの領域が二つに分かれ、それぞれの領域に一つずつタブが出る

## B-005: 分割した領域の間のタブの移動

GIVEN ファイルタブの領域が二つに分かれ、一方の領域に二つのタブがある
WHEN 利用者がそのうち一つのタブを、もう一方の領域のタブの列へドラッグする
THEN そのタブは、もう一方の領域に移る

## B-006: 分割した領域でファイルを開く

GIVEN ファイルタブの領域が二つに分かれ、フォーカスが一方の領域にある
WHEN 利用者がファイル一覧で、どの領域にもタブの無いファイルの行を押す
THEN フォーカスのある領域に、そのファイルのタブが開く
AND もう一方の領域のタブは変わらない

## B-007: タブを閉じる

GIVEN ファイルタブの領域に二つのファイルタブがある
WHEN 利用者が一方のタブを閉じる
THEN そのタブが消え、もう一方のタブが残る

## B-008: タブの並べ替え

GIVEN ファイルタブの領域に二つのファイルタブが並んでいる
WHEN 利用者が先頭のタブを、同じ列のもう一方のタブの後ろへドラッグする
THEN 二つのタブの並びが入れ替わる

## B-009: ファイルタブは中央の pane へ動かせない

GIVEN ファイルタブの領域にファイルタブがあり、中央の pane に Terminal のタブがある
WHEN 利用者がファイルタブを中央の pane へドラッグする
THEN 中央の pane にファイルタブは出ず、ファイルタブは元の領域に残る

## B-010: 中央の pane のタブは右カラムへ動かせない

GIVEN ファイルタブの領域にファイルタブがあり、中央の pane に Terminal のタブがある
WHEN 利用者が Terminal のタブをファイルタブの領域へドラッグする
THEN ファイルタブの領域に Terminal のタブは出ず、Terminal のタブは中央の pane に残る

## B-011: メニュー「タブ」がファイルタブに効く

GIVEN ファイルタブの領域に二つのファイルタブがあり、中央の pane に Terminal のタブがあり、フォーカスがファイルタブの領域にある
WHEN 利用者がメニュー「タブ」の「タブを閉じる」を選ぶ
THEN 選択中のファイルタブが閉じる
AND 中央の pane の Terminal のタブは残る

## B-012: メニュー「タブ」が中央の pane に効く

GIVEN ファイルタブの領域にファイルタブがあり、中央の pane に二つの Terminal のタブがあり、フォーカスが中央の pane にある
WHEN 利用者がメニュー「タブ」の「次のタブ」を選ぶ
THEN 中央の pane で選択中のタブが、もう一方の Terminal のタブに替わる
AND ファイルタブの領域で選択中のタブは変わらない

## B-013: アプリを起動し直したときの復元

GIVEN 利用者がファイルタブの領域を二つに分け、それぞれにファイルタブを開き、一つのタブを Diff 表示の base 比較にしている
WHEN 利用者がアプリを起動し直し、同じ worktree を選び、右カラムで「ファイル」の面を選ぶ
THEN ファイルタブの領域が同じ分割で出て、各領域に同じファイルのタブが同じ選択で出る
AND Diff 表示の base 比較にしていたタブは、Diff 表示の base 比較で出る

## B-014: worktree を選び直したときの復元

GIVEN 二つの worktree があり、利用者が一方の worktree でだけファイルタブを開いている
WHEN 利用者がもう一方の worktree を選び、元の worktree を選び直し、右カラムで「ファイル」の面を選ぶ
THEN 元の worktree で開いていたファイルタブが出る

## B-015: ほかの面への切り替え

GIVEN 利用者が右カラムの「ファイル」の面でファイルタブを開いている
WHEN 利用者が右カラムで Node・Source Control・Thread のいずれかを選ぶ
THEN 右カラム全体がその面に替わり、ファイル一覧とファイルタブの領域は出ない

## B-016: 「ファイル」の面へ戻る

GIVEN 利用者が「ファイル」の面でファイルタブを開いたあと、右カラムで Thread の面を選んでいる
WHEN 利用者が右カラムで「ファイル」の面を選ぶ
THEN ファイル一覧と、開いていたファイルタブが出る

## B-017: ファイル一覧のヘッダー

GIVEN 利用者が worktree を選んでいる
WHEN 利用者が右カラムで「ファイル」の面を選ぶ
THEN ファイル一覧の上のヘッダーの左に、検索の入力欄が出る
AND ヘッダーの右に、「差分のみ」の切り替えと「IDE で開く」ボタンが出る
AND 「差分のみ」の切り替えは、ファイルタブのヘッダーの「Diff 表示」の切り替えと同じ見た目で出る
AND 「IDE で開く」ボタンは、ファイルタブのヘッダーの「外部エディタで開く」ボタンと同じ見た目で出る

## B-018: 名前で検索する

GIVEN worktree の、利用者が開いていないディレクトリの中に、名前に入力の文字が順に現れるファイルと、現れないファイルがある
WHEN 利用者が検索の入力欄にその文字を入れる
THEN ファイル一覧に、一致したファイルと、そこへ至るディレクトリが木の形で出る
AND そこへ至るディレクトリは開いた状態で出る
AND 一致しないファイルは出ない

## B-019: 文字の間と大文字小文字

GIVEN worktree に、名前の中に入力の文字が、間に別の文字を挟み、大文字と小文字の違う形で、順に現れるファイルがある
WHEN 利用者が検索の入力欄にその文字を入れる
THEN そのファイルがファイル一覧に残る

## B-020: ディレクトリの名前の一致

GIVEN worktree に、名前が入力に一致するディレクトリがあり、その中に、名前が入力に一致しないファイルがある
WHEN 利用者が検索の入力欄にその文字を入れる
THEN そのディレクトリの行はファイル一覧に残る
AND その中の一致しないファイルは出ない

## B-021: 除外された項目の検索

GIVEN worktree に、`.gitignore` で除外され、名前が入力に一致するファイルがある
WHEN 利用者が検索の入力欄にその文字を入れる
THEN そのファイルがファイル一覧に残る
AND `.git` ディレクトリとその中の項目は出ない

## B-022: 検索をやめる

GIVEN 利用者がいくつかのディレクトリを開いた状態で検索の入力欄に文字を入れ、ファイル一覧が絞り込まれている
WHEN 利用者が検索の入力欄を空にする
THEN ファイル一覧は、検索を始める前の木に戻る
AND 検索を始める前に開いていたディレクトリは開いた状態で、閉じていたディレクトリは閉じた状態で出る

## B-023: 「差分のみ」で絞り込む

GIVEN worktree の、利用者が開いていないディレクトリの中に、git の状態が付いているファイルと、付いていないファイルがある
WHEN 利用者が「差分のみ」を入れる
THEN ファイル一覧に、git の状態が付いているファイルと、そこへ至るディレクトリが木の形で出る
AND 残ったディレクトリは開いた状態で出る
AND git の状態が付いていないファイルは出ない

## B-024: 削除されたファイル

GIVEN worktree で、追跡されているファイルが作業ツリーから削除されている
WHEN 利用者が「差分のみ」を入れる
THEN 削除されたファイルはファイル一覧に出ない

## B-025: 「差分のみ」を切る

GIVEN 利用者がいくつかのディレクトリを開いた状態で「差分のみ」を入れている
WHEN 利用者が「差分のみ」を切る
THEN ファイル一覧は、「差分のみ」を入れる前の木に戻る
AND 「差分のみ」を入れる前に開いていたディレクトリは開いた状態で、閉じていたディレクトリは閉じた状態で出る

## B-026: 検索と「差分のみ」の併用

GIVEN worktree に、名前が入力に一致し git の状態が付いているファイル、名前が入力に一致し git の状態が付いていないファイル、名前が入力に一致せず git の状態が付いているファイルがある
WHEN 利用者が検索の入力欄にその文字を入れ、「差分のみ」を入れる
THEN 名前が入力に一致し git の状態が付いているファイルと、そこへ至るディレクトリだけがファイル一覧に出る

## B-027: worktree を外部エディタで開く

GIVEN 利用者が Settings で外部エディタを選び、worktree を選んでいる
WHEN 利用者がファイル一覧のヘッダーの「IDE で開く」を押す
THEN 選択中の worktree のディレクトリが、Settings で選んだ外部エディタで開く

## B-028: 以前に中央の pane へ保存されたファイルタブ

GIVEN この変更より前の版が、ある worktree の中央の pane にファイルタブを保存している
WHEN 利用者がこの変更を含む版でその worktree を選ぶ
THEN 中央の pane にファイルタブは出ない
AND 右カラムの「ファイル」の面のファイルタブの領域に、そのファイルのタブは出ない

## B-030: ディレクトリの名前とファイルの名前にまたがる入力

GIVEN worktree に、ディレクトリとその中のファイルがあり、入力の文字は、ディレクトリの名前とファイルの名前をつなげると順に現れるが、どちらの名前にも単独では順に現れない
WHEN 利用者が検索の入力欄にその文字を入れる
THEN そのディレクトリも、その中のファイルも、ファイル一覧に出ない

## B-031: ファイル一覧とファイルタブの領域の境界

GIVEN 利用者が右カラムの「ファイル」の面を開いている
WHEN 利用者がファイル一覧とファイルタブの領域の境界を左右へドラッグする
THEN ファイル一覧の幅とファイルタブの領域の幅が、ドラッグした向きに応じて変わる

## B-032: 検索で残るファイルの上限

GIVEN worktree に、名前が入力に一致するファイルが 512 件より多くある
WHEN 利用者が検索の入力欄にその文字を入れる
THEN ファイル一覧に残るファイルは 512 件である
AND ファイル一覧のヘッダーの下に、結果が一致の一部だけであることと、入力を増やして絞り込むよう促す文が出る

## B-033: 上限に達しない検索

GIVEN worktree に、名前が入力に一致するファイルが 512 件以下ある
WHEN 利用者が検索の入力欄にその文字を入れる
THEN ファイル一覧に、一致したファイルが全部残る
AND 結果が一致の一部だけであることを示す文は出ない

## B-034: 続けて入力したときの絞り込み

GIVEN worktree に、1 文字目の入力にだけ名前が一致するファイルと、2 文字の入力に名前が一致するファイルがある
WHEN 利用者が検索の入力欄に、250 ミリ秒より短い間隔で 2 文字を続けて入れる
THEN ファイル一覧には、2 文字の入力に一致するファイルと、そこへ至るディレクトリだけが残る
AND 1 文字目の入力にだけ一致するファイルは、途中でもファイル一覧に出ない

## B-035: ファイルを worktree ごと外部エディタで開く

GIVEN 利用者が Settings で外部エディタを選び、ファイルタブでファイルを開いている
WHEN 利用者がファイルタブのヘッダーの「外部エディタで開く」を押す
THEN 選択中の worktree のディレクトリとそのファイルが、Settings で選んだ外部エディタで一度に開く

## B-036: 読めないディレクトリがある worktree の検索

GIVEN worktree に、読む権限の無いディレクトリと、その外に名前が入力に一致するファイルがある
WHEN 利用者が検索の入力欄にその文字を入れる
THEN ファイル一覧に、一致したファイルが残る
AND 読む権限の無いディレクトリの中の項目は、ファイル一覧に出ない
