## B-001: 絞り込みに合うタスクの一覧が購読で届く

GIVEN Notion の設定が揃った Repository がある
WHEN 画面がタイトルの絞り込み・ラベルの絞り込み・件数を指定してタスクの一覧を購読する
THEN その絞り込みに合うタスクが、先頭から指定した件数まで届く
AND その件数の先にまだタスクがあるかが届く

## B-002: Load more で件数を増やした一覧が届く

GIVEN タスクの一覧を購読して表示しており、続きのタスクがある
WHEN 利用者が「Load more」を押す
THEN 件数が 20 件増えた一覧が購読で届く
AND その一覧が届くまで、画面は前の一覧を表示し続ける

## B-003: 絞り込みが無いことは引数を渡さないことで表す

GIVEN Notion の設定が揃った Repository がある
WHEN 画面がタイトルの絞り込みもラベルの絞り込みも渡さずにタスクの一覧を購読する
THEN 絞り込まないタスクの一覧が、先頭から指定した件数まで届く

## B-004: ラベルの並び順が違うだけの購読は同じ対象になる

GIVEN ある Repository・絞り込み・件数でタスクの一覧の購読がある
WHEN ラベルの絞り込みの並び順だけが違う購読を始める
THEN 2 つの購読は同じ購読の対象として扱われ、同じ一覧が届く

## B-005: ラベルの選択肢が購読で届く

GIVEN Notion の設定が揃った Repository がある
WHEN 画面がその Repository のラベルの選択肢を購読する
THEN Notion のデータベースのラベルの選択肢が届く

## B-006: Notion 側の変化が届く

GIVEN タスクの一覧とラベルの選択肢を購読している
WHEN Notion 側でタスクやラベルの選択肢が変わり、Issue の一覧の取り直しと同じ契機が来る
THEN 変わった後のタスクの一覧とラベルの選択肢が届く

## B-007: 設定の保存・削除で取り直す

GIVEN ある Repository のタスクの一覧とラベルの選択肢を購読している
WHEN その Repository の Notion の設定が保存または削除される
THEN 保存・削除の後の設定で取り直した結果が届く

## B-008: 取得の失敗が前の値とともに届く

GIVEN タスクの一覧とラベルの選択肢を購読しており、前に取れた値がある
WHEN Notion からの取り直しに失敗する
THEN 前に取れた値と、取得の失敗の両方が画面に届く

## B-009: 単発の呼び出しで取る手段が無い

GIVEN daemon の client 向けの呼び出しの一覧がある
WHEN タスクの一覧またはラベルの選択肢を取る単発の呼び出しを探す
THEN そのような呼び出しは存在しない

## B-010: 空白だけの設定は検証でも未設定になる

GIVEN token または database ID が空白だけである
WHEN 利用者が設定の検証を行う
THEN 検証の結果は「未設定」になる
AND Notion API は呼ばれない

## B-011: 揃っていない設定ではタスクとラベルを取らない

GIVEN ある Repository の保存された設定の token または database ID が、空または空白だけである
WHEN 画面がその Repository のタスクの一覧またはラベルの選択肢を購読する
THEN Notion API は呼ばれない
AND 設定が無いことを示す失敗が、Notion からの取得の失敗と区別して画面に届く
