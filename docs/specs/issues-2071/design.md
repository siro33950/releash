# Design

## 変える部分

- マウス入力状態の復元: snapshot の復元後も、Codex が設定したマウス追跡方式、座標形式、alternate scroll を維持する。根拠: R-001「マウス追跡方式、座標の送信形式、alternate scroll の有効・無効を維持する」、B-001「会話の表示がスクロールする」、B-002「上下キーの入力は送られない」。ルート: 委任
- 貼り付け設定の復元: snapshot の復元後も、Codex が設定した bracketed paste の有効・無効を維持する。根拠: R-002「bracketed paste の有効・無効を維持」、B-003「同じ bracketed paste の設定に従った入力を受け取る」。ルート: 委任
- focus 通知設定の復元: snapshot の復元後も、Codex が設定した通知の有効・無効を維持する。根拠: R-003「focus 通知の有効・無効を維持」、B-004「通知の有無と内容は復元を挟まない場合と同じ」。ルート: 委任
- キーボード設定の復元: snapshot の復元後も、画面ごとの kitty keyboard の入力方式と保存した設定への復帰を維持する。根拠: R-004「それぞれの画面に対して設定された入力方式を維持する」、B-005「同じ方式のキー入力を受け取る」、B-006「保存していた設定へ戻し」。ルート: 委任
- 入力設定の継続: snapshot の復元後に Codex が設定を変更・解除した場合も、継続して出力を受信した場合と同じ入力方式になるようにする。根拠: R-005「その出力を継続して受け取った場合と同じ状態になる」、B-007「復元を挟まず同じ設定変更を受信した場合と同じになる」。ルート: 委任
- 保存状態からの復元: 本変更後に受信した入力設定と、復元に必要な情報が残る旧保存状態について、保存された端末状態から snapshot を作り直した場合も入力方式を復元する。根拠: R-005「保存された端末状態から snapshot を作り直した場合にも、この性質を維持する」、B-008「その保存状態までの出力を継続して受信した場合と同じになる」。ルート: 委任
