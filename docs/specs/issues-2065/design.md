# Design

## 変える部分

- workflow 行の集計対象: 一覧独自の最大 attempt による絞り込みを解消し、実行木と共通の対象判定から Node 数と Session の状態列を得る。根拠: R-001「同じ workflow の実行木から retry の履歴とその配下の部分木を除いた範囲」、R-002「R-001 の集計対象に含まれる Session 一つにつき一つ」、B-001・B-002・B-003。ルート: 対象判定を一つの規則に統一する。具体的な実装方法は委任。

## 固定するルート

一覧と実行木の対象判定を一つの規則に統一する。
delegate だけに適用する別の集計規則は設けない。
具体的な型、関数、配置の指定はない。

## 変えないもの

なし。

## 未確定・リスク

なし。
