## 要求

**種別**: バグ修正
**現在の挙動**: Diffビューのスクロールバーがブラウザ/OSデフォルトのスクロールバーで表示される
**期待する挙動**: 他のパネル（FileTree、TerminalPanel等）と同じカスタムスクロールバーが適用される
**背景**: アプリ全体でカスタムスクロールバーを使用しているが、Diffビューだけデフォルトのスクロールバーが残っており、UIの統一感が損なわれている

## 振る舞い定義

```gherkin
Feature: Diffビューのカスタムスクロールバー
  Diffビューのスクロールバーが他のパネルと同じカスタムUIで表示される

  Rule: Diffビューのスクロール領域はカスタムスクロールバーを使用する
    Scenario: コードDiffビューで縦スクロールが発生する場合
      Given コンテンツが表示領域を超えるコードDiffが表示されている
      When ユーザーがDiffビューを閲覧する
      Then カスタムスクロールバーで縦スクロールできる

    Scenario: コードDiffビューで横スクロールが発生する場合
      Given 表示領域の幅を超える長い行を含むコードDiffが表示されている
      When ユーザーがDiffビューを閲覧する
      Then カスタムスクロールバーで横スクロールできる

  Rule: スクロールバーマーカーは引き続き表示される
    Scenario: Diff位置マーカーの表示
      Given 変更を含むコードDiffが表示されている
      When ユーザーがDiffビューを閲覧する
      Then スクロールバー上にDiff位置を示すカラーマーカーが表示される
```
