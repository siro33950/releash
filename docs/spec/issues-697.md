## 要求

**種別**: 新機能
**ゴール**: AgentChatのメッセージ入力欄で `@` をタイプするとファイルパスのオートコンプリートを表示し、選択したファイルの内容をメッセージに含めてAgentに渡せるようにする
**背景**: Cursor, Windsurf, GitHub Copilot Chat, Claude Code が採用している事実上の標準パターン。Agentにファイルを参照させたい場合に、手動でパスを入力する手間を省く
**制約**:
- 対象はファイルパスのみ（シンボル補完は対象外）
- メンションされたファイルの内容を読み取り、メッセージのコンテキストとしてAgentに渡す
- 行範囲の指定もサポートし、指定された場合はその範囲のみを渡す
**影響範囲**: AgentChatのメッセージ入力UI、メッセージ送信処理

## 振る舞い定義

```gherkin
Feature: ファイルパスメンション
  AgentChatのメッセージ入力欄で@をタイプするとファイルパスのオートコンプリートを表示し、
  選択したファイルの内容をメッセージに含めてAgentに渡す。
  行範囲の指定により、ファイルの特定部分のみを渡すこともできる。

  Rule: @入力でオートコンプリートが起動する
    Scenario: @をタイプするとファイルパス候補が表示される
      Given メッセージ入力欄にフォーカスがある
      When ユーザーが「@」をタイプする
      Then 現在のワークツリー内のファイルパス候補リストが表示される

    Scenario: @に続けて文字を入力すると候補がファジーマッチで絞り込まれる
      Given オートコンプリート候補リストが表示されている
      When ユーザーが「@」の後にテキストを入力する
      Then 入力テキストにファジーマッチするファイルパスのみが候補に表示される

    Scenario: 一致する候補がない場合
      Given オートコンプリート候補リストが表示されている
      When ユーザーが入力したテキストにファジーマッチするファイルパスが存在しない
      Then 候補リストが非表示になる

  Rule: 候補を選択するとファイルパスがメッセージに挿入される
    Scenario: 候補を選択する
      Given オートコンプリート候補リストが表示されている
      When ユーザーが候補からファイルパスを選択する
      Then 「@」とフィルタテキストが選択されたファイルパスに置換される
      And オートコンプリート候補リストが閉じる
      And メッセージ入力欄にフォーカスが戻る

  Rule: オートコンプリートをキャンセルできる
    Scenario: Escapeキーでキャンセルする
      Given オートコンプリート候補リストが表示されている
      When ユーザーがEscapeキーを押す
      Then オートコンプリート候補リストが閉じる
      And 入力中のテキストはそのまま残る

    Scenario: @を削除してキャンセルする
      Given オートコンプリート候補リストが表示されている
      When ユーザーがバックスペースで「@」を削除する
      Then オートコンプリート候補リストが閉じる

  Rule: ファイルパスに行範囲を指定できる
    Scenario: 行範囲を指定してファイルの一部を渡す
      Given メッセージにファイルパスメンションが含まれている
      When ユーザーがファイルパスの後に行範囲を指定する
      Then メンションが行範囲付きファイルパスとして認識される

    Scenario: 行範囲を指定しない場合はファイル全体を渡す
      Given メッセージにファイルパスメンションが含まれている
      When 行範囲が指定されていない
      Then ファイル全体がコンテキストとして扱われる

  Rule: メンションされたファイルの内容がAgentに送信される
    Scenario: ファイル全体をAgentに送信する
      Given メッセージに行範囲なしのファイルメンションが含まれている
      When ユーザーがメッセージを送信する
      Then ファイル全体の内容が読み取られる
      And ファイル内容がメッセージのコンテキストとしてAgentに送信される

    Scenario: ファイルの指定行範囲をAgentに送信する
      Given メッセージに行範囲付きのファイルメンションが含まれている
      When ユーザーがメッセージを送信する
      Then 指定された行範囲のみが読み取られる
      And 行範囲の内容がメッセージのコンテキストとしてAgentに送信される

  Rule: メンションされたファイルパスが視覚的に区別される
    Scenario: メンションの表示
      Given メッセージにファイルパスメンションが挿入されている
      When ユーザーがメッセージ入力欄を見る
      Then ファイルパスメンションが通常テキストと視覚的に区別して表示される
```

## 実装仕様

**対応方針**: ファイルパスメンション機能を実現するために、Rust側に全ロジック（ファイル一覧取得・ファジーマッチ・メンション解析・ファイル読み取り・プロンプト組み立て）を実装し、フロント側はUIの表示・入力受付に徹する。

**対象コンポーネント**:

### Rust側（ロジック）

- **`src-tauri/src/file_mention.rs`（新規）**: ファイルメンション専用モジュール
  - `list_mentionable_files(worktree_path, query)` コマンド: ワークツリー内のファイルパス一覧を`.gitignore`尊重で取得し、`query`によるファジーマッチ（subsequence match）で絞り込んだ結果を返す。既存`collect_all_files`と異なり拡張子フィルタなし（全ファイル対象）。`ignore` crateを使用
  - `resolve_mentions(worktree_path, content)` コマンド: メッセージテキスト内のメンション（`@filepath` / `@filepath:L10-L20`）をパースし、各ファイルの内容を読み取り、コンテキスト付きプロンプトを組み立てて返す
- **`src-tauri/src/agent_sdk.rs`**: `send_agent_message` 内で `resolve_mentions` を呼び出し、メンション解決済みのプロンプトを `start_agent_turn` に渡す
- **`src-tauri/src/lib.rs`**: 新規コマンドの登録

### フロント側（UI）

- **`src/components/panels/AgentChatPanel/MentionPopup.tsx`（新規）**: `@`トリガーのオートコンプリートUI。既存`SlashCommandPopup`と同じ構造（Radix Popover + listbox）を踏襲
- **`src/components/panels/AgentChatPanel/MessageInput.tsx`**: `@`入力の検出、MentionPopupの表示制御、候補選択時のテキスト挿入、キーボード操作（ArrowUp/Down, Enter/Tab, Escape）のハンドリング
- **`src/hooks/useSessionStore.ts`**: 変更不要（`content`をそのまま渡し、Rust側で解決）

### 設計判断

- **ファジーマッチはRust側で実行**: フロントはクエリ文字列をRust側に渡し、Rust側がファジーマッチを行って絞り込み済みの候補を返す。フロントは受け取った候補をそのまま表示するだけ
- **メンション解決はRust側で実行**: フロントはメンションを含むテキストをそのまま`send_agent_message`に渡し、Rust側でパース→ファイル読み取り→プロンプト組み立てを全て行う
- **ファイル一覧の取得範囲**: `.gitignore`尊重、全拡張子対象（既存`collect_all_files`のLSP拡張子フィルタは適用しない）
- **行範囲の書式**: `@filepath:L10-L20`（L始まり、1-indexed）
- **メンションの視覚的区別**: 入力中はプレーンテキスト`@filepath`のまま表示。送信済みメッセージ内ではバッジスタイル（背景色付き、丸角）で区別
- **プロンプト組み立てフォーマット**:
  ```
  <file_context>
  <file path="src/main.rs">
  ファイル内容...
  </file>
  <file path="src/lib.rs" lines="10-20">
  行範囲の内容...
  </file>
  </file_context>

  ユーザーのメッセージテキスト
  ```

**影響するテスト**:
- **Rust単体テスト**: `file_mention.rs`内にメンションパース・ファジーマッチ・ファイル読み取り・プロンプト組み立てのテスト
- **フロント単体テスト**: `MentionPopup.test.tsx`（表示・選択・キーボード操作）、`MessageInput.test.tsx`（`@`検出・メンション挿入の追加テスト）
- **既存テスト**: `MessageInput.test.tsx`の既存テストが壊れないことの確認
