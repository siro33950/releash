# Issue #833: ファイル一覧のファイル名右クリックでパスをコピーしたい

## 要求

**種別**: 新機能
**ゴール**: Diffレビュービューのファイル一覧で、ファイル名を右クリックした際にコンテキストメニューからパスをコピーできるようにする。相対パス（リポジトリルートからの相対パス）と絶対パスの両方をコピーできる。
**背景**: エディタとしての基本的な利便性。ファイルパスのコピーは一般的なエディタ・IDEで標準的に提供されている機能であり、ターミナル操作や他ツールとの連携で頻繁に使用される。
**影響範囲**: Diffレビュービューのファイル一覧コンポーネントに右クリックコンテキストメニューを追加。既存のクリック操作（ファイル選択）には影響しない。

## 振る舞い定義

```gherkin
Feature: Diffファイル一覧のパスコピー
  Diffレビュービューのファイル一覧で、ファイル名を右クリックしてパスをクリップボードにコピーできる。

  Rule: 右クリックでコンテキストメニューが表示される
    Scenario: ファイル名を右クリックするとコンテキストメニューが表示される
      Given Diffレビュービューにファイル一覧が表示されている
      When ファイル名を右クリックする
      Then 「相対パスをコピー」「絶対パスをコピー」を含むコンテキストメニューが表示される

  Rule: 相対パスをクリップボードにコピーできる
    Scenario: 「相対パスをコピー」を選択するとリポジトリルートからの相対パスがコピーされる
      Given ファイル名の右クリックメニューが表示されている
      When 「相対パスをコピー」を選択する
      Then リポジトリルートからの相対パスがクリップボードにコピーされる

  Rule: 絶対パスをクリップボードにコピーできる
    Scenario: 「絶対パスをコピー」を選択するとファイルシステムの絶対パスがコピーされる
      Given ファイル名の右クリックメニューが表示されている
      When 「絶対パスをコピー」を選択する
      Then ファイルシステム上の絶対パスがクリップボードにコピーされる
```

## 実装仕様

**対応方針**: Diffファイル一覧のパスコピー機能を実現するために、`DiffFileTree` コンポーネントの `TreeNode`（ファイルノード）にRadix UI `ContextMenu` を追加し、右クリックで「相対パスをコピー」「絶対パスをコピー」を選択可能にする。

**対象コンポーネント**:
- `src/components/panels/DiffFileTree.tsx`: `TreeNode` のファイルノード部分を `ContextMenu` でラップ。コンテキストメニューに2つのコピー項目を追加
- `src/components/panels/ReviewPanel.tsx`: `rootPath` を `DiffFileTree` に渡す（propsの追加）

**技術選定**:
- Radix UI `ContextMenu`: 既に `src/components/ui/context-menu.tsx` として導入済み。TerminalPanelで使用実績あり
- `navigator.clipboard.writeText()`: 既存のクリップボードコピーパターンに準拠

**ロジック配置の判断**:
- 相対パス: `DiffTreeNode.path` として既にフロント側に保持済み（Rustから取得済みのデータ）
- 絶対パス: `rootPath`（worktreeのルートパス）+ `"/"` + `node.path` の文字列結合。表示用フォーマットの範疇でありRustコマンド不要

**影響するテスト**:
- `DiffFileTree.test.tsx`: コンテキストメニューの表示テスト、クリップボードコピーの動作テストを追加
