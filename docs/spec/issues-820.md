## 要求

**種別**: バグ修正
**現在の挙動**: AgentChat内のコードブロック（`<pre>`）でネイティブのスクロールバーが表示されている。テーブル要素ではScrollArea（Radix UI）のカスタムUIを使用しているが、コードブロックには適用されていない。
**期待する挙動**: コードブロックもテーブルと同様に、ScrollArea + ScrollBarのカスタムUIで横スクロールを実現する。
**背景**: AgentChat内でUI表示の一貫性が欠けている。テーブルはカスタムScrollAreaを使用しているのにコードブロックはネイティブスクロールバーのまま。

## 振る舞い定義

```gherkin
Feature: AgentChatコードブロックのカスタムスクロールバー
  AgentChat内のコードブロックで、テーブルと同様にカスタムUI（ScrollArea）による横スクロールを提供する。

  Rule: コードブロックはカスタムScrollAreaで横スクロールする
    Scenario: コードブロックの横幅がコンテナを超える場合
      Given AgentChatにコンテナ幅を超えるコードブロックが表示されている
      When ユーザーがコードブロックを確認する
      Then カスタムScrollBar（Radix UI）による横スクロールバーが表示される
      And ネイティブの横スクロールバーは表示されない

    Scenario: コードブロックの横幅がコンテナに収まる場合
      Given AgentChatにコンテナ幅に収まるコードブロックが表示されている
      When ユーザーがコードブロックを確認する
      Then 横スクロールバーは表示されない
```
